# Local ONNX Model Assets Directory

Place exported `.onnx` models in this folder so they are bundled as static assets on Vercel:

1. `yolov8n.onnx` — Generated by running `python ml/export_model.py` (~12.2 MB).
2. `yolov8n-food20.onnx` — Optional custom 20-class South Asian & Global Food YOLOv8 model trained with `ml/food20_dataset.yaml`.

Note: Even if `yolov8n.onnx` is not committed to Git, the web application automatically downloads the open-source `yolov8n.onnx` binary from a verified static mirror on first launch and caches it in your browser's IndexedDB.
